# Requisitos Funcionais (RF)

### RF01 — Cadastro e consulta de produtos
O sistema deve permitir que usuários autorizados cadastrem produtos com suas informações, incluindo nome, descrição ou características e preço, e consultem os produtos cadastrados.

### RF02 — Edição e exclusão de produtos
O sistema deve permitir que usuários autorizados atualizem os dados de um produto ou o removam do catálogo.

### RF03 — Controle de estoque
O sistema deve permitir registrar e consultar a quantidade disponível de cada produto e atualizar essa quantidade conforme as operações de entrada e venda.

### RF04 — Cadastro e consulta de clientes
O sistema deve permitir cadastrar clientes, armazenar seus dados cadastrais e consultar os registros existentes.

### RF05 — Consulta de endereço por CEP
Durante o cadastro ou edição de um cliente, o sistema deve permitir consultar um serviço externo de CEP para preencher dados de endereço, quando essa integração estiver disponível.

### RF06 — Registro de vendas e pedidos
O sistema deve permitir registrar uma venda por meio da criação de um pedido associado a um cliente e aos produtos e quantidades comprados.

### RF07 — Consulta de pedidos e histórico de compras
O sistema deve permitir consultar pedidos registrados e visualizar o histórico de compras associado aos clientes.

### RF08 — Consulta gerencial da loja
O sistema deve apresentar informações que apoiem o acompanhamento do estoque e das vendas realizadas.

### RF09 — Controle de acesso às operações
O sistema deve restringir operações administrativas e de gerenciamento de dados aos usuários que possuam a permissão correspondente.
